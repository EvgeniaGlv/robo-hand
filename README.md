# Сайт со статусом кнопки

Сайт, отображающий статус кнопки. Статус можно изменять через параметры в URL.

## Как использовать

1. Откройте сайт;
2. Чтобы изменить статус, добавьте в URL:
   * `?button_on` — включить кнопку;
   * `?button_off` — выключить кнопку.

## Демонстрация

* Текущий статус: **Выключена** (по умолчанию);
* При добавлении `?button_on`: **Включена**.


# Роборука с 3 пальцами

## Идея

Роботизированная рука с тремя пальцами, расположенными под углом 120° друг к другу, обеспечивает надёжный захват объектов различной формы, включая шарообразные. Каждый палец состоит из трёх фаланг и управляется независимо — это позволяет адаптировать захват под размер и форму предмета.

## Пальцы

* 3 пальца, расположены симметрично (120° между соседними);
* между фалангами установлены пружины для возврата в исходное (разжатое) положение;
* индивидуальное управление каждым пальцем;
* для каждого сустава фаланги используется сервомотор.
